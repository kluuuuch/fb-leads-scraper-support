# FB Leads Scraper Support

This public repository is the support tracker for the FB Leads Scraper Chrome extension. It contains support documentation and issue templates only; the extension source code is not hosted here.

## Report a bug

[Open the bug report form](https://github.com/kluuuuch/fb-leads-scraper-support/issues/new?template=bug_report.yml)

Use only synthetic or fully redacted examples. Never include:

- real lead names, phone numbers, email addresses, or Facebook IDs;
- webhook URLs, API keys, access tokens, or credentials;
- screenshots or diagnostics that expose personal or customer data.

If useful, export sanitized diagnostics from the extension settings and review the file before attaching it. Diagnostics are never attached automatically.

## Security or privacy vulnerability

Do not open a public issue. [Report the vulnerability privately](https://github.com/kluuuuch/fb-leads-scraper-support/security/advisories/new).

General product questions and feature requests are not accepted in this tracker yet. Public issues are limited to reproducible bugs.
