# Security Policy

## Reporting a vulnerability

Do not disclose security or privacy vulnerabilities in a public issue.

[Submit a private vulnerability report](https://github.com/kluuuuch/fb-leads-scraper-support/security/advisories/new).

Use synthetic or fully redacted evidence. Do not include real lead data, webhook URLs, access tokens, API keys, credentials, or customer identifiers. Include the affected extension version, a concise impact description, and reproducible steps when safe to do so.

We will acknowledge and investigate valid reports, but this repository does not promise a public response-time SLA.
